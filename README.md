# Каріна Ренар — авторський сайт

Сайт Каріни Ренар на Cloudflare Workers.

## Публікація

GitHub: гілка `main`. Cloudflare Workers Builds автоматично розгортає сайт після нового коміту.

- Build command: порожньо
- Deploy command: `npx wrangler deploy`
- Статичні файли: `public/`
- Назва Worker: `karina-renar-book`

Контактна форма працює через Form.taxi. Не публікуй приватні ключі чи паролі в репозиторії.
